NexaTI – Sistema de Chamados de TI

Projeto Integrador Multidisciplinar IV – UNIP

Sobre o projeto

O NexaTI é um sistema de gerenciamento de chamados de suporte técnico, desenvolvido em linguagem C como parte do Projeto Integrador Multidisciplinar IV do curso de Análise e Desenvolvimento de Sistemas.

Funcionalidades

Cadastro de chamados.

Listagem de chamados cadastrados.

Pesquisa de chamados por identificador.

Atualização do status dos chamados.

Relatórios por status e prioridade.

Armazenamento dos dados em arquivo.

Tecnologias utilizadas

Linguagem C.

Compilador GCC (MinGW-w64/MSYS2).

Visual Studio Code.

Execução

O programa pode ser compilado utilizando o comando:

gcc -std=c11 -Wall -Wextra sistema_chamados_nexati.c -o NexaTI.exe

Para executar:

./NexaTI.exe

Autor

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas – UNIP.
